# MPC-MAP: Autonomous Robot Navigation
This repository contains the source code for a semester project developed for the MPC-MAP course. The primary objective of this project is to implement an autonomous navigation pipeline for a mobile robot.

## Project Overview
The system is designed to handle the complete navigation, allowing the robot to autonomously find its way through map. The project focuses on three main capabilities:

- **Localization:** Accurately determining and tracking the robot's position within a given map or environment.
- **Path Planning:** Calculating an optimal, collision-free route from the robot's current location to a specified target destination.
- **Navigation:** Executing the planned trajectory, driving the robot, and adjusting movements to safely reach the goal.
